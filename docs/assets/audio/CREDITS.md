# 음원 출처

모두 **CC0 (퍼블릭 도메인)** 이라 출처 표시 의무는 없지만 감사의 뜻으로 적는다. 원본은 OpenGameArt.org 에서 받았고,
`tools/audio_prep.py` 로 앞뒤 무음을 자르고 음량을 맞춰 MP3 로 바꿨다.
