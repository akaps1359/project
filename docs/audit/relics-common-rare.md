# 일반·희귀 유물 밸런스 감사

범위: `game/src/data/relics.js` 의 rarity 1(일반) 33종 · rarity 2(희귀) 23종. 보스·방랑자·시작·이벤트 유물과 core 코드는 건드리지 않았다.

## 1. 방법

- **가치 측정:** `node tools/itemval.js 120 --only=relic --ids=(일반·희귀 56종) --seed=5000|7000`. 유물을 시작부터 쥐여 주고 같은 시드의 '아무것도 없는' 기준선과 비교한다(평균 도달 깊이 차이 = **층**, 승률 차이 = **%p**). 시작부터 주므로 상한치다. 두 시드 평균을 쓴다.
  - 기준선: 승률 27.5% / 28.3%, 깊이 43.60 / 43.50.
  - 같은 유물의 시드 간 차이가 흔히 1~3층(예: 고요의 구슬 +1.98 / -1.65)이라, 두 시드 평균도 대략 **±1층**은 노이즈로 본다.
- **변형 측정:** 새 도구 `tools/relvar.js` 로 relics.js 를 고치지 않고 mods 만 바꾼 변형을 한꺼번에 쟀다(itemval 과 같은 방식·출력). 두 시드 × 120판으로 2라운드(22변형)를 돌린 뒤 값을 정했다.
- **집계:** 새 도구 `tools/relaudit.js` 가 여러 결과 파일을 합쳐 등급별 중앙값·기대 범위(중앙값 ±0.8층)를 계산하고 벗어난 것에 '사기?'·'약함?'을 붙인다.
- **전체 확인:** `node tools/sim.js 160 smart --cmd=all --asc=N --seed=3000|4000` 를 수정 전(원본 워크트리)과 수정 후에 같은 시드로 돌렸다.

### 등급별 기대 범위

| 등급 | 수정 전 중앙값 | 목표 |
|---|---:|---|
| 일반 | +2.12층 | **+1.3 ~ +3.0층** (중앙 +2) |
| 희귀 | +1.65층 | **+2 ~ +4층** (일반보다 높게) |

수정 전 희귀 중앙값이 일반보다 **낮았다**(목표 2 위반). 희귀 하위권 대부분이 휴식처·탐험 유물이라 봇이 못 쓰는 탓이 크지만(아래 4장), 전투 유물인 불씨·거인잡이 새총·호박 속 벌레·철갑 소라도 일반 중앙값보다 낮았다.

## 2. 전/후 표

'후'는 수정한 값으로 같은 두 시드를 다시 잰 것이다. **주의:** 유물은 판 중에도 떨어지므로 유물을 바꾸면 기준선도 바뀐다(수정 후 기준선 26.7% / 28.3%, 깊이 43.48 / 42.34 — 평균 약 0.6층 낮아짐). 그래서 '후' 값은 약 0.6층 부풀려져 있다.

## 5. 남은 문제와 제안 (core 수정이 필요해 이번 범위 밖)

1. **소원 물레(희귀, +5.84층)** 는 여전히 희귀 최상위다. 주기 5전투가 run.js 에 박혀 있어 relics.js 로 조정할 수 없다. 제안: `M.prayerWheel` 을 주기로 읽게 해 7전투로.
2. **자명종:** `buffs.watch = 4` · `aspd += 0.6` 을 mods 값으로 읽게 하면 지속 6초 등으로 올릴 수 있다.
3. **무쇠 아령:** [단련] +6%가 run.js 에 박혀 있다. 피해% 칸 희석을 피하려면 단련을 '모든 클래스 강화 +1'(곱연산 칸이지만 3번 한정)로 바꾸는 것도 방법이다.
4. **웃음꽃 relicState:** 이제 `happyFlower` mod 를 쓰는 유물이 없다. battle.js 의 happyFlower 분기와 stats.js AUTO 의 'happyFlower' 는 죽은 코드가 된다(동작에는 문제 없음, 예전 세이브의 relicState 도 무해).
5. **봇 평가 한계:** smart 봇이 증강 새로고침·[단련]·[명상]·[발굴]·증강 건너뛰기를 거의 쓰지 않는다. tools/simbot.js 에서 이것들을 평가하게 되면 4장의 보류 항목을 다시 재야 한다. 또한 simbot 의 무료 소환 어림은 `startRare` 를 확률과 무관하게 3으로 본다(출정 배낭을 봇이 고를 때 과대평가 가능).
6. **불씨·웃음꽃 최종값:** 마지막 확인(시드 9000, 60판)에서 둘 다 +4층 안팎이 나왔다. 60판이라 노이즈가 크지만 전체 난이도를 맞출 때 120판 × 2시드로 다시 재 보길 권한다. 높게 나오면 웃음꽃 8%, 불씨 35%.
7. **docs/GAME_DESIGN.md 4장 유물 표**는 이번 규칙상 고치지 않았다. 바뀐 11종의 설명을 표에 반영해야 한다.
8. 버팀 닻(일반, +0.89)·산딸기(+1.30)·대장장이 모루(+1.21)는 범위 아래 가장자리지만 노이즈 안이라 두었다.
