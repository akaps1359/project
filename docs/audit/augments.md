# 증강 밸런스 감사 (RS.AUGMENTS)

대상: `game/src/data/content.js` 의 증강 59종. 바꾼 파일은 증강 정의와 새 측정 도구 두 개(`tools/augstack.js`, `tools/augwin.js`)뿐이다. 전역 난이도(RS.BAL)·엔진·봇은 건드리지 않았다.

## 1. 측정 방법

| 도구 | 무엇을 보나 | 이번 설정 |
|---|---|---|
| `tools/itemval.js --only=aug` | 증강 하나를 시작부터 쥐여 주고 같은 시드 기준선과 비교 (평균 도달 깊이 차이 '층', 승률 차이 %p). 상한치다 | 120판 × 시드 5000·7000, 두 시드 평균 |
| `tools/picks.js` | 실제 판에서 제시된 횟수 대비 봇이 고른 비율 | 150판 × 시드 5000·7000 합산 |
| `tools/augstack.js` (새로 만듦) | 같은 증강 여러 장·연마본·조합을 시작부터 쥐여 줌. `--sets="sharp*3;eagle,eagle+"` | 100판, 시드 5000 |
| `tools/augwin.js` (새로 만듦) | content.js 를 고치지 않고 증강 mods 를 덮어써서 전체 승률 A/B. 어떤 변경이 전체 승률을 움직였는지 한 번에 가른다 | 360~400판 × 시드 5000·9000 |

**오차.** 120판 itemval 한 번의 층 차이는 표준오차가 약 ±1.5층이라, 두 시드 평균도 ±1층쯤 흔들린다(예: 암살 교본 +4.0 / +0.3). 그래서 한쪽 시드에서만 튄 것은 건드리지 않고, **두 시드 모두 같은 방향으로 벗어나고 고른 비율도 같은 말을 하는 것**만 고쳤다. 후 측정의 층 수치는 기준선이 달라진 뒤의 값이라(바뀐 증강들이 기준선의 판에도 나온다) 전과 1:1로 비교하면 안 되고, 등급 안의 순서를 보는 용도다.

**등급별 기대 범위 (itemval 두 시드 평균).** 전 측정에서 등급 평균이 은빛 +2.2 · 황금 +3.1 · 프리즘 +4.4층으로 순서는 이미 맞았다. 이를 중심으로 은빛 +1.5~3.5, 황금 +2.5~4.5, 프리즘 +3.5~6층을 '정상'으로 잡았다. 즉시 효과(신병 모집·승급·피의 헌납·골드 러시·빛의 세례)와 조건부 보상(순수 혈통·다양성·전설의 위엄 등)은 범위 아래여도 고른 비율을 함께 보고 판단했다.

**되돌린 시도.** 처음에는 도자기 대포 +60→50%, 독안개 0.6→0.5%, 치명적 일격 치명 피해 +50→40%, 산울림 대가 +10% 도 넣었다. `augwin.js` 로 가르니 **봇이 자주 고르는 증강 하나를 깎을 때마다 전체 승률이 2~4%p씩** 떨어져(합계 약 -11%p), 기준 ±3%p 를 크게 벗어났다. 이 셋은 황금·프리즘 범위 상단이긴 해도 밖은 아니라서 되돌렸다.

picks.js(각 150판)로도 asc0 28.7 / 29.3% → 25.3 / 30.7% 로 같은 수준이다. 심연 5 는 +4%p 로 약간 높게 나왔으니 메인 세션의 전체 난이도 조정 때 참고.

## 5. 중첩 확인 (augstack.js, 100판, 전 수치)

| 매의 눈 ×2 / ×3 | +8.4 / +9.7 | +24 / +28%p | 1장부터 과했음 → 사거리 하향 |
| 거인 사냥꾼 ×2 / ×3 | +4.3 / +6.2 | +17 / +24%p | 선형 이하 (곱연산 칸이지만 엘리트·보스 전용) |

## 6. 봇이 잘못 평가하는 것 (시뮬의 한계)

- **소환·합성 경제를 크게 낮춰 본다.** 행운의 합성(고른 비율 7~11%, itemval 프리즘 1위), 도박꾼의 주사위(5~9%, 황금 1위), 행운의 소환(17%), 재활용(4~6%), 쌍둥이 소환(21%), 소환 할인(7~8%), 신병 모집·승급·피의 헌납(10~14%). 봇의 가치 함수가 '합성이 늘어 복리로 커지는' 효과를 한 번의 모의로는 못 본다. **사람은 이것들을 훨씬 자주 고를 것**이라 행운의 합성·도박꾼은 itemval 기준으로 깎았다.
- **둔화·즉시 피해를 높게 본다.** 시간 왜곡(74%)·끈적한 땅(63%)·과부하(84%)·다양성(78%)·독안개(85%)는 itemval 에 비해 많이 고른다. 그래서 이 증강들을 깎으면 봇 승률이 크게 떨어진다(4장 '되돌린 시도').
- **대장간 할인·곱절 단련·검은 풀무**: 봇이 강화에 골드를 과하게 쓰는 탓인지 강화 할인이 itemval 에서 음수~낮게 나온다. 대장간 할인은 봇이 46% 고르는데 전 itemval 이 -0.4층이었다.
- **조건부 보드 구성**: 순수 혈통(3클래스 이하)·다양성(5클래스)을 봇은 판매·배치로 맞추려 하지 않는다. 순수 혈통이 낮게 나오는 것은 절반쯤 이 탓이다.
- **즉시 효과는 itemval 에서 낮게 나온다** (시작할 때 빈 보드에서 발동): 빛의 세례(+1.6층이지만 고른 비율 58%), 신병 모집, 골드 러시.

## 7. 남은 문제와 제안

1. **산울림·행운의 합성은 여전히 프리즘 상단**(후 +7.8 / +8.1층, 오차 감안해도 +6 이상). 산울림은 봇이 92% 고른다. 대가를 +10% 로 올리면 봇 전체 승률이 약 3%p 떨어지므로, 메인 세션이 난이도를 다시 맞출 때 함께 올리기를 권한다. 행운의 합성은 8% 로 되돌린 뒤 재측정 전이다.
2. **순수 혈통**은 +75% 로도 +1.2층. 수치만으로는 한계가 있다. 제안(엔진 수정 필요, 이번에는 안 함): 조건을 '가장 많은 클래스가 보드의 절반 이상'처럼 맞추기 쉬운 형태로 바꾸거나, 합성 결과 클래스를 보드의 클래스 중에서 고르게 하기.
3. **대장간 할인 계열의 음수·저평가**는 봇의 강화 판단을 먼저 봐야 한다(tools/simbot.js, 이번 범위 밖).
4. **도자기 대포·배수의 진**(+5.7·5.8층, 고른 비율 82·44%)은 프리즘 상단이다. 대가(누수 2배, 최대 생명 절반)는 3막까지 걸리므로 목표 3은 만족하지만, 도자기 대포는 사기 후보로 남는다. 깎으면 전체 승률이 떨어지므로 난이도 재조정과 함께 +55% 정도를 권한다.
5. **독안개**(황금, 고른 비율 85%)와 **치명적 일격**(79%)도 '늘 고르는' 쪽이다. itemval 은 황금 상단(+4.4 / +4.0)이라 이번에는 두었다.
6. **심연 5 승률 +4%p** (한 시드 +7, 다른 시드 +2). 오차 안일 수도 있지만 메인 세션에서 전체 sim 으로 확인 필요.
7. 시너지 키워드 연결: #화상·독(불화살↑ → 역병 확산), #기절·빙결(전사 훈련·서리 결정↑ → 얼음 깨기)은 재료를 올렸다. #치명타(암살 교본 +2.1층, 17%)는 재료가 여전히 약한 편이지만 중첩 시 치명 확률이 1 에서 잘리는 구조라 그대로 두었다.
