## 1. 핵심 루프

```
[지휘관·심연 선택] → [별점술사: 별점 4택]
  ↓
[맵] 갈림길에서 다음 칸 선택 (층마다 1칸, 되돌아갈 수 없음)
  ├ 전투 / 엘리트(성난 엘리트) ─→ [전투] 소환·합성·배치로 웨이브 3개 버티기 ─→ [보상] 골드 + 증강 3택(+ 유물 · 소모품)
  ├ ? ─→ 이벤트(대부분) · 전투 · 상점 · 보물. 이벤트가 나올수록 다른 것이 나올 확률이 오른다
  ├ 상점 ─→ 유물·증강·소모품·용병 구매, 제거·룬 새기기 서비스
  ├ 휴식처 ─→ 휴식 / 수련 / 연마 / (유물·퀘스트에 따라) 명상·발굴·단련·부화·복제·회수…
  └ 보물 ─→ 유물, 또는 푸른 봉인석
  ↓ 18층 보스 → 보스 유물 3택 → 다음 막 [차원 방랑자: 강력한 선택 3택]
3막 보스를 쓰러뜨리면 클리어. 봉인석 3개가 있으면 4막(휴식처 → 상점 → 엘리트 → 휴식처 → 고대신 옴네크)으로.
```

전투 안에서는 랜덤 디펜스의 손맛(뽑기 → 3개 모아 합성 → 등급 상승)을, 전투 밖에서는 로그라이크의 빌드 설계(어떤 증강·유물·룬을 모을지, 어느 길로 갈지, 봉인석을 노릴지)를 즐기는 구조다. **유닛·골드·생명·강화 레벨·룬은 모험 내내 이어진다.**

## 2. 전투 규칙

| 항목 | 규칙 |
|---|---|
| 보드 | 4×5 = 20칸. 한 칸에 **같은 유닛(클래스+등급) 3기까지**(전설은 4기) 쌓인다 |
| 길 | 보드를 둘러싼 사각 루프. 적은 왼쪽 위 균열 문에서 나와 시계 방향으로 돈다 |
| 누수·빠져나감 | 일반 적은 한 바퀴를 돌아 균열 문에 닿으면 **생명 -1과 함께 빠져나간다**(놓친 만큼만 아프다). 엘리트·보스는 균열에서 다시 나와 **계속 돌며**, 처음엔 조금이지만 **돌 때마다 두 배**로 앗아 간다(엘리트 1→2→4→8, 보스 3→6→12→24, 고대신 9→18→36). 오래 끌수록 기하급수로 위험하다 |
| 균열 게이지 | 일반 적이 한 바퀴의 뒤쪽(오른쪽 길부터 균열까지)에 머물면 문 둘레 고리가 찬다(뒤로 갈수록 빠르게). 가중 시간 25초 분량이 쌓이면 **생명 -1**. 뒤쪽 길에 적이 없으면(잡거나 빠져나가면) 게이지가 초당 5%씩 서서히 가라앉는다. '놓쳤는가'가 아니라 '얼마나 가까이 오게 두었는가'를 보므로 전투마다 조금씩 닳는다 |
| 강타(의도) | 엘리트·보스는 머리 위 **! 와 붉은 숫자**로 예고한 뒤 생명을 친다(엘리트 1~2, 1막 보스 2, 2·3막 보스 3, 고대신 4). 준비하는 동안 **노란 경직 막대**(체력 4~10%)를 채우도록 몰아치거나 **기절·빙결**시키면 끊긴다(끊긴 적은 잠시 경직). 강타를 준비하는 동안은 **집중 모드**: 시간이 40%로 느려지고, 그 적 둘레만 밝게 남으며, 그 적에게 닿는 유닛 칸에 금색 꺾쇠가, 패널 위에 이름·피해·경직 막대 띠가 뜬다. 느려진 틈에 강한 유닛을 끌어다 가까이 옮겨 몰아친다 |
| 생명 | 시작 25. 전투가 끝나도 이어지고, **막을 넘어가면 모두 회복**(심연 4부터 잃은 생명의 75%). 휴식처는 30% 회복 |
| 상처 | 생명을 깎은 강타마다 1 (최대 8). 하나당 **다음 전투부터** 모든 유닛 피해 ×(1 − 0.04×상처) (피해% 묶음과 따로 곱한다, 전투 중에는 시작 값 고정). 휴식처 [휴식]으로 모두 낫고(시든 꽃의 낙인·각성제면 못 고친다), 일반 전투를 이길 때마다 1씩 아물고, 새 막에서는 사라진다. 휴식을 '생명이 가득해도 고를 이유가 있는' 선택으로 만든다 |
| 생명 보호 | 유령 망토·혼령 빙의·철갑 소라·버팀 닻·되감기 모래는 **일반 적**의 누수만 완전히 막는다. 엘리트·보스가 새면 피해를 **절반**으로만 줄인다(횟수가 있는 보호는 한 번 쓴다). 목적: 쫄몹이 새서 터지는 것을 막는 보험 |
| 보스 기술 | 보스마다 기술을 따로 돌린다: 점액·진흙(2×2 칸 공격 속도 -45~50%), 광기의 시선(모든 칸 -35%), 보호막(체력 8~12%, 먼저 깨야 체력이 깎인다), 부하 소환, 균열(칸 기절), 럼 한 모금(모든 적 +35% 속도), 약탈(골드 15%), 영혼 흡수(주변 적이 죽으면 회복), 차원 뒤섞기(유닛 자리 뒤섞기), 순간이동(체력 70%·40%에서 길 앞쪽으로), 각성(2단계). **가로지르기**(4막 사도): 경고 뒤 보드를 곧장 가로질러 돌진해 지나간 칸을 기절시키고, 도착하면 스스로 기절. **봉인**(고대신): 장막을 두를 때 높은 등급 유닛을 봉인(칸이 아니라 유닛, 신화는 불가), 장막을 깨면 풀림. 처음 쓰는 기술은 이름과 설명이 뜬다 |
| 필드 상한 | 필드에 적이 **60마리**가 되면 즉시 패배 (일반 적이 빠져나가므로 거의 일어나지 않는다. 성능 상한 역할) |
| 소환 | 골드로 무작위 유닛 소환. 비용 = 10 + 지금까지 소환 횟수 (모험 전체 누적). 5% 희귀, 0.5% 영웅. **클래스는 모두 같은 확률** (지휘관 성향 가중치는 v2.14에서 없앴다). 빈칸이 있어야 소환할 수 있다 |
| 판매 | 그 유닛에 **들인 골드**의 50%를 돌려받는다 (미다스 75%, 최대 80%). 합성하면 재료에 들인 골드가 결과로 넘어간다. 보상·무료로 얻은 유닛은 조금만 받는다 (6×3^등급의 절반) |
| 합성 | 같은 칸의 같은 유닛 3기(전설은 4기) → **다음 등급의 무작위 클래스** 1기. 일반 → 희귀 → 영웅 → 전설 → 신화. 소환으로는 영웅까지 |
| 신화 스킬 | 신화는 기본 공격이 전설 4기와 비슷하고(피해 ×150, 간격 ×0.74), 힘은 자동 스킬과 봉인 면역에서 나온다. 대지 가르기(5초, 주변 200% + 기절), 화살비(4초, 적 6명 130%), 운석 낙하(6초, 350% 광역), 그림자 처형(체력 10% 이하 즉사 + 치명 연쇄), 절대 영도(7초, 1.2초 빙결 + 150%) |
| 배치 | 끌어서 자리 바꾸기, 또는 유닛을 고른 채 다른 칸(빈칸·유닛)을 누르면 옮기거나 서로 바꾼다. 바깥 14칸은 길과 가깝고 안쪽 6칸은 멀어 **근접(전사·도적)은 바깥, 원거리는 안쪽**이 유리. 새로 소환한 유닛은 클래스에 맞는 빈칸에 놓이고, 이미 놓인 유닛은 직접 끌어서 옮긴다(자동 [정리]는 없앴다: 보스가 자리를 뒤섞는 기믹이 의미를 갖도록) |
| 룬 | 보드 칸에 새겨져 모험 내내 남는다. 그 칸에 선 유닛에게 효과 (피해·공속·사거리·골드·둔화·치명·메아리·복제, 나쁜 룬 [금 간 칸]) |
| 웨이브 | 전투당 3웨이브, 16초 간격. 필드를 일찍 비우면 곧바로 다음 웨이브 + 빠른 정리 보너스 골드 |
| 골드 | 처치 골드(막마다 ×1/×1.6/×2.2) + 웨이브 시작 골드(6/10/14) + **이자**(보유 10골드당 1, 최대 5) + 클리어 보상 |
| 강화 | 클래스별 레벨당 피해 +18% (모든 등급에 적용, 상처를 보충하려고 15%에서 올렸다). 비용 30 + 20×레벨 |
| 보스 | 보스 등장 후 75초 제한. 넘기면 **폭주**(속도 ×1.8, 누수·강타 피해 ×2) |
| 상성 | 돌골렘·흑기사·철갑 게: 가벼운 물리(궁수·도적) 50% 감소 / 유령: 물리 40% 감소 / 리치: 물리 25% 감소 |

## 3. 모험 2.0 — 슬더스 1·2에서 가져온 것

> 구조는 슬더스에서 빌려 왔지만, 원작 이름을 그대로 옮긴 용어·유물·증강·저주·이벤트는 이 게임만의 이름으로 바꿨다 (심연·차원 방랑자·별점술사·봉인석·고대신 옴네크 등). 옛 이름 → 새 이름 대응은 저장소 루트의 `MAPPING.md`.

### 3-1. 참고 대응표

| 1 · 네오 | 4줄 축복(작은/중간/대가 있는 큰/보스 유물 교환) | **별점술사**의 점괘 4줄 | 대가 "골드를 모두 잃음"은 첫 전투 즉사 함정이라 **"3번의 전투 동안 웨이브 골드 없음"**으로 교체 (6장) |

### 3-2. 맵

- 5갈래 × 17층 + 보스 층. 경로 6개를 아래에서 위로 그리며 **서로 X자로 엇갈리지 않게** 만든다 (슬더스1 알고리즘)
- 고정 층: 1층 전투(2막부터 30%는 ?), 7~10층 중 한 층 보물, 17층 휴식처(보스 직전), 18층 보스. 중간 휴식처 최소 2개
- **지형**: 막마다 하나 — 평범한 길 / 장터 길(상점↑) / 야영지 숲(휴식처↑) / 안개 낀 길(?↑) / 격전지(엘리트↑, 2막부터) / 보물 사냥터(보물 칸) / 고요한 길(전투↓ 이벤트↑)
- **? 칸**: 전투(가끔 엘리트)·상점·보물·드물게 휴식처, 나머지는 이벤트
- 난이도는 막 안에서 오른 비율로 정한다: 1층→진행도 1, 보스 층→10 (층이 늘어도 막 끝 난이도는 같다)
- 나머지 층 가중치: 전투 45 · ? 22 · 상점 5 · 엘리트 8(심연 1+: 13, 4층부터) · 휴식처 12(4층부터, 8층 제외)
- 규칙: 엘리트·휴식처·상점은 부모 칸과 연속 금지, 같은 부모를 둔 형제 칸끼리 같은 특수 방 금지. 막마다 엘리트 1개·상점 1개 보장
- **성난 엘리트**: 막마다 엘리트 하나에 불꽃. 무작위 강화(체력 +40% / 속도 +30% / 재생 / 받는 피해 -25%)를 받고, 이기면 골드 +30×막과 초록 봉인석
- 축지 장화(유물): 연결되지 않은 다음 층 칸으로도 이동 (3회)

### 3-5. 차원 방랑자 (2·3막 시작)

막을 넘어가면 차원 틈새에서 차원 방랑자 하나가 나타난다. 방랑자마다 **풀 3개**가 있고 풀마다 하나씩 뽑아 세 가지를 보여 준다 — 예를 들어 탐욕의 용 바르가는 "경제 유물 / 상점 유물 / 즉시 보상" 풀에서 하나씩. 반드시 하나를 골라야 한다. 방랑자 유물 18종은 보스 유물급이며 대가가 있는 것이 많다 (피의 왕관: 모든 유닛 피해 +30% / 전투 시작마다 생명 -2). 전체 목록은 4장.

### 3-6. 봉인석과 4막

| 봉인석 | 얻는 법 | 포기하는 것 |
|---|---|---|
| 붉은 봉인석 | 휴식처 [회수] | 그 휴식처의 회복·수련·연마 |
| 초록 봉인석 | 성난 엘리트 처치 | 강화된 엘리트를 상대하는 위험 |
| 푸른 봉인석 | 보물 상자에서 유물 대신 | 유물 하나 |

세 개를 모두 가진 채 3막 보스를 쓰러뜨리면 4막 **잠든 신의 제단**: **휴식처 → 상점 → 엘리트(방패 사도·창 사도) → 휴식처 → 고대신 옴네크**. 사도들은 길을 도는 대신 **보드를 가로질러 돌진**한다(경고 → 지나간 칸 기절 → 도착 후 스스로 기절): 도는 시간이 짧아지는 긴박함과 대가를 함께 준다. 고대신은 촉수 달린 거대한 눈으로, 1초에 최대 체력의 2.8%까지만 피해를 받는 고대의 몸에 **광기의 시선**(9초마다 모든 유닛 공격 속도 -35% 2.5초), 하수인(임프) 소환, **사도 부르기**(20초, 창 사도), **봉인의 장막**(18초, 체력 8% 보호막 + 높은 등급 유닛 2칸 봉인, 장막을 깨면 해방), **혼돈의 속삭임**(13초, 유닛 4기 자리 뒤섞기), 균열(12초, 2×2 칸 기절)을 쓰고, 체력 50%에서 **완전히 깨어나** 빨라지고 기술을 더 자주 쓰며 봉인이 한 칸 늘어난다.

**피해 한도와 한 바퀴 시간.** 고대신은 속도 14로 한 바퀴(572px)에 약 41초를 걷는다. 그런데 17초마다 **깊은 잠**(4.5초)에 빠져 제자리에 멈추므로 실제 한 바퀴는 약 52초다. 잠든 동안에는 초당 1%씩 회복하지만 받는 피해 한도가 1.5배(초당 4.2%)로 커진다. 체력 100%에 장막(8%씩)과 각성 장막(6%), 잠자며 회복하는 양을 더하면, 한도를 꽉 채우는 덱은 약 45~50초 만에 쓰러뜨린다. 곧 한 바퀴 안에 끝나므로 누수가 없다. 한도의 절반 정도를 내는 덱은 1.5~2바퀴가 걸려 누수 1~2번(생명 14씩)을 내준다. 즉 늦추기(빙결)에 몰빵하지 않아도 이길 수 있고, 잠든 틈에 몰아치는 덱이 이득을 본다(보스 둔화는 원래 절반만 먹힌다). 제한 시간은 75+25초다. 한도는 최대 체력에 비례하므로 체력을 올려도 강한 덱의 처치 시간은 그대로다. 난이도는 누수(14)와 제한 시간으로 맞췄다(4막 도달 189판 중 격파 43%). v2.14 지휘관 개편 뒤에는 덱의 꾸준한 화력이 낮아져(예전 시작 유물의 클래스 피해 +60% 가 빠짐) 진 판이 한도의 8분의 1밖에 내지 못해, 체력을 42 → 27 로 낮췄다. 한도가 최대 체력에 비례하므로 한도를 채우는 강한 덱의 처치 시간은 그대로다.

**기술 예고.** 모든 보스 기술은 쓰기 전에 알린다. 알리는 방식은 다섯 가지다.
- **머리 위 ! 와 준비 막대:** 기술 색으로 표시되고, 끝나 갈수록 빨리 깜빡인다.
- **보스 바 두 번째 줄:** 기술 이름, 남은 초, 효과, 대처법(예: "약탈: 지금 써 버리면 안 뺏겨요!")을 보여 준다. 쉬는 동안에는 "다음: 깊은 잠 · 6초"를 띄운다. 이 줄은 보스전 내내 자리를 잡아 두어 캔버스 크기가 바뀌지 않는다.
- **대상 미리 표시:** 봉인될 유닛에는 보랏빛 조준 꺾쇠, 자물쇠, 보스에서 이어지는 사슬이 붙는다. 자리를 바꿀 칸은 짝마다 다른 색의 꺾쇠와 점선으로 잇는다. 준비 중에 합성으로 신화가 되면 봉인을 피한다. 약탈을 준비하면 골드 표시가 깜빡인다. 점액·균열·닻·돌진은 칸 경고와 경로 경고로 알린다.
- **체력바 노란 눈금:** 각성·분열·순간이동이 일어나는 체력에 눈금을 긋는다.
- **첫 안내:** 전투마다 기술을 처음 쓸 때 긴 안내 토스트를 한 번 띄운다. 고대신의 피해 한도에 처음 걸렸을 때도 설명한다.

준비 시간은 보호막 1.6초, 뒤섞기 1.8초, 약탈 2.4초, 럼 1.4초, 회복 1.6초, 소환 1.2초, 잠 1.3초다. 준비 중에는 다른 기술 대기 시간이 멈춘다.

### 3-7. 지휘관·심연·연대기

- **지휘관 3명** (v2.14): 슬더스 캐릭터처럼 **고유 능력**(전투 중 버튼) + **전용 증강 8종** + 작은 시작 유물. 소환 클래스는 모두 같은 확률이다.
  - **브론**(기사단장, 처음부터) · [방패 돌진] 결의 2개: 강타를 준비하는 적(없으면 엘리트·보스, 그다음 가장 앞선 적)을 들이받아 강타를 끊고 큰 피해(엘리트·보스는 최대 체력 7% + 그 웨이브 적 기본 체력만큼, 나머지는 적 기본 체력의 3배), 주변 적 1초 기절. 결의는 전투 시작에 2, 웨이브마다, 그리고 유닛이 강타를 끊을 때마다 +1 (최대 5). 시작 유물 강철 문장: 전투 시작 결의 +1, 전사 기절 +5%p
  - **엘라**(대현자, 2막에 도달하면) · [원소 전환] 12초마다: 화염 태세는 모든 공격이 화상(초당 그 피해의 20%), 냉기 태세는 15% 둔화. 바꿀 때 원소 폭발로 모든 적에게 최대 체력의 4% (엘리트·보스 0.4%). 준비 시간에도 태세만 미리 바꿀 수 있다. 시작 유물 마나의 샘: 원소 폭발 +30%
  - **아스트라**(별의 섭정, 한 번 클리어하면) · [별똥별] 별 3개: 모든 적에게 그 웨이브 적 기본 체력의 1.5배 (보스는 35%). 엘리트가 강타를 준비할 때 떨어뜨리면 경직(체력 7~8%)을 넘겨 강타가 끊긴다. 별은 웨이브마다 +1, 전투가 끝나도 남는다 (최대 5). 시작 유물 별의 왕홀: 전투 시작 별 +1
  - 지금 능력을 쓰면 준비 중인 강타를 끊을 수 있으면 능력 버튼이 **금빛으로 반짝인다** (방패 돌진은 늘, 별똥별은 한 방이 남은 경직을 넘을 때)
- **전용 증강**: 증강 선택지의 첫 장이 25% 확률로 그 지휘관의 전용 증강에서 나온다. 또 지휘관의 고유 능력을 #고유 능력 시너지 1개로 치므로, 처음부터 '빌드 쪽으로 당기기'(세 번째 장 50%)가 전용 증강 쪽으로 향한다. 첫 보상 화면에 전용 증강이 하나 이상 보일 확률은 세 지휘관 모두 약 75%다 (시작 유물은 이 계산에 넣지 않는다: 유물마다 태그 수가 달라 지휘관별 빈도가 달라지지 않게, 시작 유물을 바꿔도 같게). 지휘관마다 두세 갈래로 나뉜다
  - 브론: 결의를 **쌓아 두기**(굳건한 의지·철벽 방진·용맹의 서약) ↔ 돌진을 **자주 쓰기**(연속 돌격·되받아치기·도발·성전), 그리고 기사단 행진(전사·도적)
  - 엘라: **화염**(불꽃 심화·업화·꺼지지 않는 불) · **냉기**(서리 심화·열충격) · **전환**(원소 순환·마력 역류·원소 합일)
  - 아스트라: 별을 **모아 두기**(별자리·천체 관측) ↔ 자주 **쏟기**(별 부스러기·은하의 축복·유성우·초신성), 별빛 서리·별의 선물은 곁들이기
- 예전 세이브의 레온·벨·카이·미라는 불러올 때 각각 브론·엘라·아스트라·엘라로 바뀌고, 빠진 시작 유물(용병 계약서·영혼 항아리·매의 깃털·연금 솥)은 조용히 빠진다
- **심연 10단계**: 클리어하면 다음 단계가 열린다. 1 엘리트 증가·체력 +15%·엘리트 강타 +1 / 2 상점 +15% / 3 일반 적 체력 +10% / 4 막 회복 절반 / 5 엘리트·보스 누수 +1 / 6 최대 생명 -4 / 7 보스 체력 +10% / 8 강화 비용 +20% / 9 심연의 짐(피해 -10%) / 10 3막 보스 둘. 강한 봇 기준으로 단계마다 고르게 어려워지게 순서를 맞췄다 (5장)
- **연대기**: 첫 모험, 1·2막 보스 격파, 첫 클리어, 두 번째 클리어, 고대신 격파, 심연 10 도전. 체험용으로 "모든 지휘관 해금" 버튼도 있다

### 3-8. 퀘스트 · 녹는 유물 · 사라지는 저주

- 퀘스트: **용의 알**(둥지 이벤트 → 휴식처 [부화]: 전설 유닛 + 유물 [아기 용]), **보물 지도**(지도 상인 → 다음 막 첫 상자 +400G), **퉁퉁 쿠폰**(골드 300 → 전투 5번 뒤 유물 3개)
- 녹는 유물: 박 등잔(8번의 전투 동안 피해 +50%, 휴식처에서 다시 켬), 밀랍 병정(공속 +40%, 전투 4번마다 10%p씩 녹음)
- 저주: 12종. 찜찜함은 전투 5번 뒤 사라지고, 심연의 짐·시든 꽃의 낙인은 없앨 수 없다

### 3-10. 저장

칸을 옮길 때마다 자동 저장(브라우저 localStorage). 전투 도중 나가면 같은 시드로 그 전투를 처음부터 다시 한다. 선택 대기열(증강 고르기·제거·룬 새기기 등)도 저장되므로 중간에 꺼도 이어진다.

## 5. 밸런스 설계

### 수치 모델
- 적 체력: `64 × 성장률^L`. L(웨이브 레벨) = 3×(진행도-1) + 웨이브 번호, 진행도 = (막-1)×10 + 층. **한 막 = 30레벨**
- 성장률은 막마다 **1.1484 / 1.1059 / 1.0893 / 1.0523(4막)** (18층 막 + 보스 기술 추가 후 "전체적으로 쉽다"는 피드백에 맞춰 올림. 스마트 봇 승률 심연0 42% · 심연5 44% · 심연10 25%, 사망은 대부분 3막. 봉인석을 노리면 4막 도달 32%, 도달하면 고대신 격파 40%). 후반일수록 보드가 차고 소환 비용이 올라 플레이어 성장도 느려지므로 막마다 따로 둔다
- 초반 완충: L이 낮을 때는 체력을 60%부터 서서히 100%로 (첫 전투 튜토리얼 구간)
- 보스 체력은 "평균 빌드의 DPS × 약 8" 근처. 보스는 한 표적이라 전체 DPS의 일부만 들어가므로 평균 빌드면 한 바퀴 안팎에 잡힌다

### 시뮬레이터
`node tools/sim.js [판수] [smart|basic|random] [--cmd=all] [--asc=N] [--keys] [--bp=이름=값] [--trace] [--set key=값]`

실제 게임 로직(`game/src/core`, `game/src/data`)을 그대로 Node에서 돌려 봇이 모험 전체(별점술사 → 맵 → 전투 → 선택 대기열 → 상점·휴식처·이벤트 → 차원 방랑자 → 4막)를 플레이한다.
- **smart 봇** (`tools/simbot.js`, v2.1): 사람처럼 판단하는 봇. 소환과 강화 중 골드당 DPS가 큰 쪽을 고르고, 이벤트·상점·휴식처 선택지는 **저장본을 복제해 미리 적용해 본 뒤** 가치 함수(골드·생명·유물·증강·유닛 전력·저주·봉인석)로 비교하며, 남은 생명과 골드로 길을 계획한다
- **basic 봇**: v2까지 쓰던 봇. 강화를 거의 하지 않는 초보자에 가깝다
- **random 봇**: 모든 선택을 무작위로, 배치는 하지 않음

v2 까지는 basic 봇으로 난이도를 맞췄는데, 강화를 제대로 쓰는 smart 봇은 **심연 0 클리어 98%**, 심연 10도 82%였다. 강화가 게임의 핵심 성장 수단인데 기준 봇이 그걸 안 써서 난이도가 크게 어긋나 있었던 것. v2.1은 smart 봇으로 기준을 다시 잡았다.

### 아이템 밸런스와 시너지 (v2.6)
**측정.** `tools/itemval.js`로 증강·유물 147종을 하나씩 시작할 때 쥐여 주고, 같은 시드 120판의 기준선과 비교했다(평균 도달 깊이 차이와 승률 차이). 시작부터 쥐여 주므로 판 전체에 걸친 가치의 상한이다. 즉시 효과(빛의 세례·신병 모집 등)는 빈 보드에서 발동해 낮게 나온다.

### 지휘관 개편 (v2.14)
**문제.** 지휘관 7명 중 여럿이 '어떤 클래스가 더 자주 나온다'(소환 가중치)로만 달랐는데, 무작위 소환·합성 게임에서 그 차이는 거의 느껴지지 않았다. 정체성은 사실상 시작 유물에 다 들어 있어서 시작 유물이 너무 강했고, 그래서 별점술사의 '시작 유물 → 보스 유물' 교환을 아무도 고르지 않았다(봇 기준 대부분 0%). 시작 유물을 약하게 하면 지휘관의 정체성이 사라진다.

**해결(슬더스 방식).** 슬더스는 캐릭터마다 카드 풀이 달라서 시작 유물을 내줘도 캐릭터가 남는다. 그래서 정체성을 유물에서 **지휘관 자체**로 옮겼다.
- 지휘관을 3명(브론·엘라·아스트라)으로 줄였다. 셋 다 전투에서 직접 쓰는 **고유 능력**(자원·규칙이 다 다름)이 있다: 결의를 모아 강타를 끊는 방패 돌진, 12초마다 태세를 바꾸며 터뜨리는 원소 폭발, 전투를 넘어 모아 두는 별로 쏟는 별똥별 (3-7절)
- 지휘관마다 **전용 증강 8종**(은빛 3 · 황금 3 · 프리즘 2). 같은 선택지에 일반 증강과 섞여 나온다(첫 장 25%, 빌드 당기기로 세 번째 장 50%). 지휘관 안에서도 쌓아 두기↔자주 쓰기, 화염↔냉기↔전환처럼 갈래가 나뉘어 덱이 달라진다
- 시작 유물은 능력을 조금 키우는 정도(결의 +1·전사 기절 +5%p / 원소 폭발 +30% / 별 +1). 교환해도 능력과 전용 증강이 남으니 강한 보스 유물과 바꿀지가 **진짜 선택**이 됐다: 봇의 교환 선택이 0~3%(카이만 20%) → 세 지휘관 모두 20~23%
- 소환·합성의 클래스는 모두 같은 확률이다
- 예전 세이브: 레온→브론, 벨·미라→엘라, 카이→아스트라. 빠진 시작 유물(용병 계약서·영혼 항아리·매의 깃털·연금 솥)은 조용히 빠지고, 별의 왕홀에 모아 둔 별은 아스트라의 별로 옮긴다

**조정.** (smart 봇, 같은 시드 300판씩 비교)

### 적대적 점검과 휴식처 재설계 (v2.13)
에이전트 131명이 버그·밸런스·선택지를 찾고, 발견마다 따로 반박 검증을 붙였다(92건 중 63건 확인). 확인된 것을 파일 묶음별로 고친 뒤 검토자 세 명이 수정 전체를 다시 반박 검증했다(11건 추가 수정).
- **휴식처가 진짜 선택이 됐다.** 원인: 막 사이 완전 회복 때문에 잃은 생명이 '죽느냐' 말고는 의미가 없어, 영구 ×1.5 인 연마가 늘 이겼다(봇 기준 휴식 6%). **상처**를 넣었다: 생명을 깎은 강타마다 상처 1(최대 8), 하나당 다음 전투부터 피해 −4%(따로 곱함). 휴식으로 모두 낫고, 일반 전투를 이길 때마다 1 줄고, 막을 넘어가면 사라진다. 상처가 쌓이면 휴식, 없으면 연마·수련이 답이다. 봇의 휴식 선택이 6% → 19~24%(심연 5 는 24%)가 됐다. 대신 강화 1레벨당 피해 +15% → +18%.
- **단련**은 피해% 합에 묻혀 한 번도 안 골랐다 → 따로 곱하는 ×1.08(최대 3번, 겹곱).
- **증강 선택지가 빌드를 당긴다:** 세 장 중 하나는 50% 확률로 내가 모은 시너지 태그(상위 2개)에서 나온다. 건너뛰기 골드 25/40/55 → 40/60/80.
- **다양성**은 공짜 +40% 였다 → 희귀 이상 유닛이 있는 클래스마다 +8%. **저주 인형**은 저주당 피해 +8%·공속 +5%, 새 은빛 증강 **업보**(저주를 얻을 때마다 골드 +30×막). **소원의 꽃** 깨달음에 최대 생명 −30%, 싸움은 보스 체력 ×1.15. 방랑자 풀에서 늘 같은 선택지·겹치는 +12 생명을 없앴다. 상점에 **황금 주문서**(사면 무조건 이득)가 안 나온다.
- **주요 버그:** 늪의 여왕 첫 강타가 잠수와 겹쳐 끊을 수 없음, 혼령 빙의 첫 웨이브 보호가 발동 안 함, 검은 풀무 연마 무효, 예전 세이브의 빠진 유물 때문에 이어하기가 막힘, 패배 연출 중에 나가면 패배를 되돌릴 수 있음, 이벤트 결과를 뒤로 가기로 되돌릴 수 있음, 새 모험 확인만 눌러도 저장이 지워짐, 강타·누수 예고 숫자가 실제와 다름(이제 RS.strikeLoss / RS.lapLoss 한 곳에서 계산), 봉인된 칸에 소환됨, 역병 확산이 3마리에 못 미침, 허수아비 시험이 '길 위의 발견'을 빼앗음, 상점 할인이 제거 서비스에 안 붙음, 음원 실패 시 0.7초마다 재시도, 승리 음악이 음소거에도 계속됨 등.
- **심연 곡선 재조정:** 심연 1 엘리트 체력 +15%(강타 +1 유지), 심연 7 보스 체력 +5%, 심연의 짐 −7%. smart 봇 승률: 심연 0 약 32%, 5 약 29%, 7 약 18%, 10 약 12%, 고대신 격파 44%.

### 여러 세션 밸런스 감사 (v2.11)
증강·일반/희귀 유물·보스/방랑자/시작 유물·적을 네 세션이 나눠 동시에 감사했다. 각 세션의 방법·전후 표·보류 이유는 `docs/audit/` 에 있다: [증강](audit/augments.md) · [일반·희귀 유물](audit/relics-common-rare.md) · [보스·방랑자·시작 유물](audit/relics-boss-ancient-start.md) · [적](audit/enemies.md).

### 중첩과 생명 대가 (v2.10)
**피해 공식.** 한 번 칠 때 피해 = 기본 × 등급 × **(1 + 피해% 합)** × **(1 + 0.18×강화 Lv)** × **(1 − 0.04×상처)** × **단련** × 치명 기대치 × (엘리트·보스 추가 피해) × (얼음 깨기) × (선제공격). 공격 횟수는 **(1 + 공격 속도% 합)** 에 비례한다.
- 롤처럼 **같은 칸(버킷) 안은 합연산, 칸끼리는 곱연산**이다. 피해%는 증강·유물·분노의 뿔·전설의 위엄·광전사가 모두 한 칸에 더해지므로, 칸이 클수록 하나를 더 얹을 때의 효율이 떨어진다. 3막 보스 기준 중앙값은 ×5.8(+478%)이라, 여기에 +15%를 더하면 실제로는 +2.6%다.
- 곱이 되는 칸은 강화(중앙 ×3.9, Lv 19), 공격 속도(×2.5), 치명(×1.2, 치명 빌드 p90 ×2.4)이다. 합치면 중앙 ×74, p90 ×137, 최대 ×423이다.
- **폭주 후보:** ① 피의 계약이 여러 번 겹쳤다 → 1회로 제한. ② 생명 대가 증강(도자기 대포 50/54판, 배수의 진 45/54, 피의 계약 38/54)이 3막 보스에 가는 판마다 들어 있었다. 대가가 한 번 깎고 끝나거나 누수에만 걸렸기 때문이다.
- **생명 대가를 소모전에 묶었다.** 도자기 대포 +70→60%, 대가는 누수·강타·균열 게이지로 잃는 생명 모두 2배. 배수의 진 +45%·공속 +15%, 최대 생명 절반에 더해 휴식처 회복 절반. 피의 계약 +35%(1회), 최대 생명 -4에 더해 막 사이 회복 절반. 과부하 공속 +25%. 독안개 0.6%. 전설의 위엄 +10%. 광전사 1당 +4%(최대 80%).
- **안 쓰이던 것 올림:** 행운의 합성 12%, 빛의 세례(+모든 클래스 강화 1), 신병 모집(희귀 1 + 일반 2), 저금통(이자 +4, 골드 +30), 피의 헌납 희귀 4기, 재활용 18%, 순수 혈통 55%, 도박꾼 실패 8%, 탐욕 대가 적 체력 +8%, 속전속결 대가 15%, 반격 +3·8%.
- **봇 평가 보강:** smart 봇이 얼음 깨기·피의 흥분·역병 확산·불화살·연속형 광전사·붉은 해골·저주 인형·약사의 반지·흡혈·반격·청동 방패의 가치를 0으로 보고 있었다(고른 비율 0~1%). 이제는 어림으로 계산한다(고른 비율 12~46%).
- **제시되었을 때 고른 비율(asc0 120판):** 프리즘 14~88%, 황금 6~90%, 은빛 7~53%이다. 전에는 프리즘 11~87%, 황금 0~97%, 은빛 1~61%였다. 아직 낮은 것은 재활용·복리·순수 혈통·소환 할인처럼 봇이 저평가하는 경제·조합형이다.
- 보스 체력을 한 번 더 20% 올렸다(1막 15.5, 2막 15, 3막 21.5). 일반 적 체력은 1막 ×1.15, 2막 ×1.1, 3막 ×0.95다. 승률은 asc0 34%, asc5 31%, asc10 15%다.

### 보스전 손맛 (v2.9)
- **누수 기하급수:** 엘리트·보스는 첫 바퀴는 가볍고(엘리트 1, 보스 3, 고대신 9), 다시 돌 때마다 두 배가 된다. 그만큼 보스 체력을 약 30% 올려(1막 13, 2막 12.5, 3막 18) '빨리 잡으면 싸고 오래 끌면 치명적'이 되게 했다.
- **흡혈:** 광전사(1/6 깎을 때마다 +1), 붉은 해골(1/4), 새 희귀 유물 피의 성배(1/8). 엘리트·보스전 중에 생명을 되찾는다. 생명을 깎아 힘을 얻는 빌드가 버틸 수단이 된다.
- **크기:** 엘리트 ×1.3, 보스 ×1.5로 그린다. 위쪽 길에서는 잘리지 않게 살짝 내린다.
- **균열 게이지 회복:** 뒤쪽 길이 비면 초당 5%씩 줄어든다.
- **강타 집중 모드:** 슬로 모션(40%), 주변 어둡게, 닿는 유닛 금색 표시, 패널 위 강타 띠, 심장 박동 소리. 게임 속 시간은 그대로라 밸런스는 바뀌지 않는다.
- **탭으로 자리 바꾸기:** 유닛을 고른 뒤 다른 유닛을 누르면 즉시 바꾼다.
- **결과:** smart 봇 승률 asc0 38%, asc5 40%, asc10 13%. 고대신은 4막 도달 100판 중 45%를 격파한다.

### 생명 관리 (v2.8)
**문제.** 플레이어는 "한 막 내내 생명이 그대로거나, 몰려서 한 번 돌면 비명횡사"라고 느꼈다. 그래서 광전사류는 쓸모가 없었다. 측정해 보니 그대로였다(asc0 140판).
- 일반 전투의 92~100%가 누수 0이었다. 새는 판은 대개 7 이상을 잃었고, 3막 일반 전투에서만 24판이 끝났다.
- 원인 ① **양의 되먹임:** 살아남은 적이 계속 돌며 한 바퀴마다 또 새고(3막에서 2·3바퀴째 누수가 99번), 적이 쌓일수록 딜이 흩어졌다.
- 원인 ② **문턱 함수:** 생명을 잃는 길이 누수 하나뿐이었다. 보드가 문턱보다 세면 0, 약하면 무너진다.
- 원인 ③ **1·2막 일반 전투가 공짜:** 층별로 재 보니 1·2막 내내 적이 한 바퀴의 뒤쪽까지 오는 일이 거의 없었다. 전투가 무너지면 끝장이라서 일반 전투를 문턱보다 한참 약하게 맞춰 둘 수밖에 없었다.

**해결.** 슬더스의 구조(적은 매 턴 공격하고, 덱은 그중 일부를 막는다 → 전투마다 조금씩 닳는다)를 실시간으로 옮겼다.
1. **빠져나감:** 일반 적은 한 바퀴를 돌면 -1과 함께 사라진다. 되먹임이 끊겨 "놓친 만큼만" 아프다. 이제 일반 전투를 문턱 가까이 맞춰도 안전하다(일반 적 체력 1막 ×1.2, 2막 ×1.2).
2. **균열 게이지:** 적이 얼마나 가까이 왔는지를 연속으로 센다. 문턱 없이 전투마다 0~몇씩 닳는다. 둔화·빙결 빌드가 게이지를 늦춘다.
3. **강타(의도):** 엘리트·보스가 숫자로 예고하고 친다. 몰아치기(폭딜)나 기절·빙결로 끊는다. 소모품(폭탄·서리 주문서)도 끊는 데 쓴다. 엘리트전이 슬더스처럼 '생명을 내주고 유물을 받는' 거래가 된다.
4. **막 사이 완전 회복**(슬더스와 같다, 심연 4부터 75%)으로 막 하나가 생명 관리 한 판이 된다. 시작 생명은 20에서 25로 올렸다(한 번 맞는 몫이 덜 거칠도록).
5. **생명 연계:** 광전사는 잃은 생명 1당 피해 +5%·공속 +1.5%로 바꿨다(문턱 → 연속). 붉은 해골은 30%. 쇠말뚝은 강타에도 적용된다. 새 아이템은 청동 방패(강타 -1, 최대 생명 +3)와 반격(강타를 끊으면 생명 +2)이다.
6. **smart 봇 위험 표**(한 판에서 x 이상 잃을 확률)를 새 규칙에서 다시 쟀다.

**결과**(asc0 140판).
| | 전 | 후 |
|---|---|---|
| 일반 전투 누수 0 (1/2/3막) | 100 / 98 / 92% | 90 / 83 / 76% |
| 2막 엘리트 전투당 잃은 생명 | 0 76%, 2~3 3%, 4~6 7%, 7+ 14% (0 아니면 크게) | 0 39%, 1 14%, 2~3 18%, 4~6 15%, 7+ 15% |
| 3막 일반 전투당 잃은 생명 | 0 92%, 1~3 1%, 4~6 2%, 7+ 5% | 0 77%, 1 6%, 2~3 7%, 4~6 5%, 7+ 5% |
| 생명이 한 번이라도 절반 이하로 내려간 판 | — | 86% |
| 30% 이하로 내려간 판 | — | 61% |
| smart 봇 승률 (asc0/5/10) | 37 / 37 / 11% | 30.5 / 27.6 / 10% |
| 고대신 격파 (4막 도달 판 중) | 32% | 36% |

사망 위치는 보스(막 끝에 낮은 생명으로 도착), 엘리트, 3막 일반 전투에 고루 퍼졌다. 생명 관련 아이템의 가치도 살아났다(시작부터 쥐여 준 가치: 흡혈 의식 +0.6 → +4.3층, 피의 계약 +0.6 → +2.6층, 광전사 +2.7층).

### 신화·보스 조정 (v2.7)
- **진단:** 신화를 가진 판은 거의 다 이겼다. 70판 중 승리 34판 가운데 13판이 신화를 가졌고, 진 판에는 신화가 없었다. 보스·엘리트는 너무 쉬웠다(1막 보스 100%, 2막 93%, 3막 79%, 엘리트 96~100%). 사망은 주로 3막 일반 전투에서 나왔다.
- **신화:** 피해 ×175 → ×150으로 내렸다. 스킬은 대지 가르기 300→200%, 화살비 8명×150% → 6명×130%, 운석 500→350%, 절대 영도 200%·1.5초 → 150%·1.2초, 그림자 처형 15→10%로 줄였다.
- **보스:** 체력을 올렸다. 슬라임 킹·늪의 여왕 8→11, 리치·해골 선장 7.5→9.5, 균열의 군주 10.5→14. 한 바퀴를 돌면 잃는 생명도 6→8로 늘렸다.
- **엘리트:** 체력 +33%, 잃는 생명 3→4.
- **일반 전투:** 1~3막 체력 성장을 되돌리고 조금 더 낮췄다(×0.999). 난이도가 보스에 몰리게 했다.
- **자동 [정리]를 없앴다.** 보스의 자리 뒤섞기가 한 번의 탭으로 무의미해지지 않게 했다. 새로 소환한 유닛은 원래대로 클래스에 맞는 빈칸에 놓인다. 시뮬레이터 봇도 5초마다 한 칸씩만 손으로 옮긴다.
- **결과:** smart 봇 승률 asc0 37%, asc5 37%, asc10 11%. 주요 사망 지점이 1~3막 보스로 옮겨 갔다(asc0 기준 3막 보스 28, 2막 보스 26, 1막 보스 10, 가장 많은 일반 전투 5). 고대신은 4막 도달 판 중 32%를 격파한다.

## 6. 모바일(아이폰 사파리) 성능 설계

### GPU 효과 층 실험 (lab.html)

본 게임과 따로 **https://randomspire.pages.dev/lab.html** 에 실험 페이지를 둔다. 게임 코드는 같고(저장도 같이 쓴다), 전장 위에 PixiJS(WebGL) 캔버스를 한 장 겹쳐 빛을 GPU에서 그린다. 본 게임 파일(index.html)에는 PixiJS도 이 코드도 들어가지 않는다.

- 구조: 겹친 캔버스는 불투명 검정 + CSS `mix-blend-mode: plus-lighter`(지원하지 않으면 `screen`)라 아래 장면에 빛을 더하기만 한다. 렌더러가 모아 두던 위층 빛 묶음(`PixelCtx.batch[1]`)을 `RS.GpuFx.take` 가 스프라이트로 옮기고, 프레임 끝에 `present` 가 한 번 그린다. 바닥 빛 웅덩이(유닛 아래)는 순서 때문에 캔버스에 남긴다
- 실험 항목(전장 왼쪽 위 LAB 단추로 하나씩 켜고 끈다): **빛 번짐**(빛 층을 흐리게 한 사본을 더함) · **주변 조명**(큰 빛마다 넓고 옅은 빛을 깔아 바닥·유닛을 물들임) · **입자 늘리기**(빛나는 입자 1.8배, 상한 420→1400, 빛나는 입자 60개 제한 해제, 분위기 입자 3배) · **도트 빛**(빛을 320×372로 계산해 픽셀 그대로 확대). 패널에 fps·그리기 시간·GPU 빛 개수가 나온다
- PixiJS는 쓰는 것만 골라 묶었다(`tools/pixi_lab_entry.mjs` → `game/vendor/pixi-lab.min.js`, 380KB · gzip 108KB). lab.html 은 약 1.2MB

헤드리스 크롬, 393×852 @3배, 3막 보스 + 엘리트 + 적 50마리, 8초 (캔버스 쪽 = 그리기 + 1px 읽기로 래스터 강제):

| | 캔버스 래스터 p50 / p95 (ms) | 캔버스 'lighter' 그리기 | GPU 빛 스프라이트 |
|---|---|---|---|
| 기존 (Canvas 2D) | 19.3 / 30.7 | 185 | 0 |
| GPU 층, 효과 추가 없음 | 14.4 / 19.0 | 55 | 127 |
| GPU 층, 전부 켬 (부드럽게) | 18.0 / 25.3 | 55 | 404 (최대 669) |
| GPU 층, 전부 켬 (도트 빛) | 16.0 / 22.3 | 55 | 476 (최대 736) |

빛을 GPU로 넘기기만 해도 캔버스 래스터가 약 25% 줄고(p95는 38%), 그 여유로 빛 3~5배·입자를 더 써도 기존보다 가볍다. 다만 헤드리스 크롬에는 실제 GPU가 없어 WebGL을 CPU로 흉내 내므로 GPU 쪽 비용과 전체 fps는 여기서 잴 수 없다(헤드리스에서는 오히려 느려진다). 아이폰에서 LAB 패널의 fps를 보고 판단한다.

## 8. 배포 — 주소 하나로 어디서나 접속 (Cloudflare Pages)

`docs/index.html` 은 외부 파일이 필요 없는 한 파일이라 정적 호스팅이면 어디든 올릴 수 있다.

지금 **https://randomspire.pages.dev** 에서 서비스 중이다(Cloudflare Pages, 무료). GitHub 주소가 드러나지 않고, 저장소를 비공개로 돌려도 계속 배포된다. 켤 때 한 일:

1. dash.cloudflare.com → Compute → Workers & Pages → Create → 맨 아래 **Continue to Pages** → Import an existing Git repository → GitHub 연결(저장소 접근 허용)
2. 저장소 `project` 선택 → Project name `randomspire` → Production branch `claude/sweet-pasteur-006yat` → Framework None, Build command 비움, Build output directory `docs` → Save and Deploy
3. 이후 이 브랜치에 푸시할 때마다 자동으로 다시 배포된다

예전에는 GitHub Pages(`akaps1359.github.io/project/`)로 올렸다. 방법은 아래와 같다(무료 요금제는 공개 저장소만 가능):

1. GitHub 무료 요금제는 **공개(public) 저장소에서만** Pages를 쓸 수 있다. 저장소 → Settings → General → 맨 아래 Danger Zone → Change visibility → Public (비공개를 유지하려면 GitHub Pro 이상)
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: `claude/sweet-pasteur-006yat`, 폴더: `/docs` → Save
3. 1~2분 뒤 **https://akaps1359.github.io/project/** 로 접속. 이후 이 브랜치에 푸시할 때마다 자동으로 갱신된다 (GitHub 주소를 숨기려면 Settings → Pages에서 끄고, 저장소를 비공개로 돌린다)
4. 아이폰 사파리에서 공유 → 홈 화면에 추가하면 앱처럼 전체 화면으로 실행된다

저장소를 공개하고 싶지 않다면 Netlify(폴더 끌어다 놓기)·Cloudflare Pages·Vercel도 무료로 비공개 저장소를 연결해 같은 방식으로 올릴 수 있다. `docs/.nojekyll` 은 GitHub Pages가 Jekyll 변환 없이 파일을 그대로 올리게 한다. 저장은 브라우저 localStorage라 기기마다 따로 남는다.
